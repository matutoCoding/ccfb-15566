# 宠型社 · 宠物毛发造型设计系统

浏览器端宠物毛发造型设计与预览系统,TypeScript + WebGPU(WGSL),面向宠物美容连锁店的「先预览、再下剪」场景。

## 运行

```bash
npm install
npm run dev    # 开发
npm run build  # 类型检查 + 生产构建
```

要求 Chrome / Edge 113+(支持 WebGPU 的浏览器)。

## 页面

| 页面 | 功能 |
| --- | --- |
| 宠物档案 | 增删改、JSON 导入导出;无外部模型,内置泰迪/比熊/雪纳瑞三种程序化体型 |
| 体型编辑 | 躯干/头身/四肢/耳尾比例滑杆,实时重建模型与毛发 |
| 毛发造型 | 剪刀/推子/梳子三种笔刷;推子可选 3/6/9/13mm 刀头;模板一键套用;撤销/重做 |
| 染色 | 分区刷染,毛根/毛尖双色渐变,流行色板 |
| 效果预览 | 造型前后分屏对比、前/后/左/右固定视角、自动旋转、导出效果图与长度分区单 |
| 设置 | 发丝数量(5万~30万)、物理迭代、重力、光照、自阴影强度 |

## 操作

- 左键:在模型上刷动造型/染色
- Shift+左键 或 右键拖拽:旋转视角
- 滚轮:缩放

## 技术要点

- **发丝渲染**:每根发丝 4 节点条带,顶点着色器按切线公告板展开,根粗梢细;Kajiya-Kay 各向异性双高光(主高光向梢偏移)+ 发根 AO + 逐缕抖动近似发间自阴影 + 身体阴影贴图,避免塑料感
- **物理**:compute shader Verlet 积分,距离约束 + 卷曲形状记忆(每根有长度/粗细/卷曲度/硬度),重力使长毛下垂,胶囊体碰撞防止穿模
- **工具**:全部走 GPU brush compute pass,只改笔刷半径内的发丝;推子在核心区域直接写入目标长度,误差为 0(远优于 0.5mm 要求)
- **性能**:30 万发丝 = 540 万顶点/帧,单 draw call 无实例化开销;模拟每帧 1 次 compute dispatch;左下角实时 FPS 角标
- **撤销/重做**:造型缓冲 GPU 快照环(12 步),笔画开始时自动记录
- **模板**:按 16 个毛发分区定义目标长度/卷曲/刚度,compute pass 混合套用,泰迪熊头/狮子装/比熊圆头/雪纳瑞标准装等
- **导出**:离屏渲染前/右/后/左四视角拼图为 PNG;分区长度统计(compute 原子归约)导出 CSV 长度分区单

## 目录结构

```
src/
  core/       GPU 上下文、轨道相机、数学库
  pet/        品种预设、程序化建模、植发采样、射线拾取
  hair/       发丝数据缓冲、模拟调度、渲染器(含阴影/分屏/离屏)
  shaders/    WGSL:模拟、笔刷、模板、发丝渲染、网格渲染、阴影、统计
  state/      档案持久化、造型模板库
  pages/      六个页面
  export/     效果图与长度分区单导出
```
